# VALOA 레이드 시트 사용법

구글 시트로 쓰던 고정 공대 레이드표를 웹으로 옮긴 것입니다.
링크만 열면 바로 쓸 수 있고, 로그인은 없습니다. 한 사람이 고치면 다른 사람 화면에도 바로 반영됩니다.

주소를 아는 사람은 누구나 수정할 수 있으니 링크는 공대 안에서만 공유해 주세요.

## 이번 주 진행 순서

1. **레이드 체크** 탭에서 이번 주에 갈 캐릭터를 체크합니다.
2. **편성 보드**에서 레이드별로 팟을 짭니다.
3. 레이드를 돌고 나면 해당 팟의 **클리어** 버튼을 눌러 둡니다.
4. **대시보드**에서 남은 레이드와 진행 상황을 확인합니다.
5. 수요일 리셋 후에는 대시보드에서 **🏁 주간 클리어 초기화**를 한 번 눌러 줍니다.

## 탭 설명

### 대시보드

처음 열리는 화면입니다. 이번 주 전체 상황을 여기서 봅니다.

- 레이드별로 팟이 어떻게 짜여 있는지, 팟 평균 전투력이 얼마인지 한눈에 보입니다.
- 문제가 있는 팟(사람 중복, 서폿 없음 등)은 맨 위 **⚠️ 지금 확인이 필요한 편성**에 모여 있습니다. 항목을 누르면 그 레이드 편성 보드로 바로 갑니다.
- 팟 칸을 누르면 해당 레이드 편성 보드로 이동합니다.
- 클리어 표시를 해 둔 팟은 `2/3팟 클리어`처럼 진행 상황이 레이드 이름 옆에 붙습니다.
- 체크는 했는데 아직 팟에 안 들어간 캐릭터는 **미편성** 칸에 모입니다.
- 아래쪽 표에서 멤버별 캐릭터 수, 체크 수, 편성된 수, 예상 골드를 봅니다.
  예상 골드는 체크한 레이드 골드를 그냥 더한 값이라 골드 획득 캐릭터 수 제한은 빠져 있습니다.

버튼 두 개가 있습니다.

| 버튼 | 언제 누르나 |
| --- | --- |
| 원본 시트 그대로 불러오기 | 원본 시트 탭에 적어 둔 고정 편성을 편성 보드에 그대로 덮어씁니다. 매주 같은 구성으로 갈 때 편합니다. |
| 🏁 주간 클리어 초기화 | 수요일 리셋 후 모든 팟의 클리어 표시를 한 번에 풉니다. 자동으로 풀리지 않으니 직접 눌러 주세요. |

### 편성 보드

레이드를 고르고 팟을 짜는 화면입니다. 위쪽 레이드 버튼으로 레이드를 바꿉니다.

**넣는 방법**

- 후보 캐릭터를 누르면 규칙에 맞는 자리에 알아서 들어갑니다. 한 번 더 누르면 빠집니다.
- 자리가 정해져 있으면 캐릭터를 끌어서 원하는 칸에 놓습니다. 이미 누가 있는 칸에 놓으면 둘이 자리를 바꿉니다.
- 편성에서 빼려면 칸의 ✕를 누르거나, 캐릭터를 끌어서 보드 빈 공간에 놓습니다.
- **⚡ 미편성 N명 자동 배치**를 누르면 남은 후보를 한 번에 채웁니다.

자동 배치 규칙은 4인 파티마다 서폿 1명 딜러 3명, 같은 사람 캐릭터는 한 팟에 겹치지 않게, 확정된 팟은 건드리지 않기입니다.
맞는 자리가 없으면 팟을 새로 만듭니다.

**팟 버튼**

| 버튼 | 뜻 |
| --- | --- |
| 클리어 | 이번 주에 이 팟이 레이드를 돌았다는 표시입니다. |
| 확정 | 인원이 덜 차도 이 인원으로 가기로 정했을 때 누릅니다. 자동 배치가 이 팟은 건너뜁니다. |
| ✕ | 팟을 삭제합니다. |

후보에 캐릭터가 안 보이면 레이드 체크 탭에서 그 레이드를 체크하지 않은 것입니다.
팟 인원은 레이드마다 4인·8인·16인 중에 고를 수 있고, 인원을 줄이면 잘려 나가는 자리의 캐릭터는 편성에서 빠집니다.

### 원본 시트

원래 시트에 있던 고정 편성을 적어 두는 곳입니다. 여기 저장해 둔 내용은 대시보드의 "원본 시트 그대로 불러오기"로 편성 보드에 가져옵니다.

- 후보 이름을 누르거나 끌어다 놓아 팟을 채웁니다.
- **현재 편성 가져오기**를 누르면 지금 편성 보드 내용을 그대로 옮겨 옵니다. 이번 주 편성을 앞으로 고정으로 쓰고 싶을 때 편합니다.
- 편집한 내용은 **원본 시트 저장**을 눌러야 반영됩니다.

### 레이드 체크

캐릭터별로 이번 주에 갈 레이드를 체크합니다. 여기서 체크한 캐릭터만 편성 보드 후보에 나옵니다.
표를 옆으로 밀어도 캐릭터 이름과 레이드 머리글은 고정돼 있습니다.

### 캐릭터

로스터를 관리하는 화면입니다.

- **캐릭터 추가**: 본부계(사람)와 캐릭터 이름을 넣고 추가하면 직업·아이템 레벨·전투력을 자동으로 받아옵니다.
- **이름 수정**: 캐릭터 이름을 누르면 바로 고칠 수 있습니다. 체크와 편성에 있는 이름도 같이 바뀝니다.
- **삭제**: 오른쪽 ✕를 누르면 체크와 편성에서도 함께 빠집니다.
- **딜러/서폿**: 역할 버튼을 눌러 바꿉니다. 자동 배치와 팟 검사에 이 값이 쓰입니다.
- **멤버 색상**: 사람마다 색을 지정할 수 있습니다. 편성 보드와 대시보드에 그 색으로 표시됩니다.
- **⟳ 전체 조회**: 모든 캐릭터의 아이템 레벨·전투력을 지금 바로 다시 받아옵니다. 캐릭터 수만큼 시간이 걸립니다.
- **로펙**: 캐릭터별 로펙 버튼을 누르면 그 캐릭터의 로펙 페이지가 새 탭으로 열립니다.

전투력·아이템 레벨·로펙 점수·젬 효율은 매일 새벽 자동으로 갱신됩니다. 급하면 전체 조회로 직접 받아오면 됩니다(로펙 점수는 새벽 갱신에서만 채워집니다).

처음 한 번은 **API 키 등록** 버튼으로 로스트아크 API 키를 넣어야 전체 조회와 캐릭터 추가 시 자동 조회가 동작합니다.
한 번 등록하면 공대원 전체가 같이 씁니다. 다만 이 키는 시트 링크를 아는 사람이 볼 수 있으니, 링크 공유 범위를 넘기지 말아 주세요.

### 골드표

레벨 구간별·레이드별 골드를 보는 표입니다. 보기 전용이라 화면에서는 수정할 수 없습니다.
시세가 바뀌었으면 담당자에게 말씀해 주세요.

## 실수했을 때

편성 보드, 원본 시트, 레이드 체크 탭에는 위쪽에 **↩ 되돌리기** 버튼이 있습니다.
누르면 마지막 저장 직전으로 돌아가고, 연달아 누르면 그만큼 더 이전으로 갑니다.
다른 사람과 동시에 편집하다 꼬였을 때도 이 버튼으로 되돌리면 됩니다.

캐릭터 탭과 골드표에는 되돌리기가 없습니다. 캐릭터 삭제와 이름 변경은 확인하고 눌러 주세요.
크게 꼬여서 되돌리기로 안 되면 매일 새벽 백업이 남아 있으니 담당자에게 말씀해 주세요.

## 이럴 땐 이렇게

| 증상 | 확인할 것 |
| --- | --- |
| 편성 보드 후보에 캐릭터가 없음 | 레이드 체크 탭에서 그 레이드를 체크했는지 봅니다. |
| 팟에 ❌ 사람 중복이 뜸 | 같은 사람의 캐릭터가 한 팟에 둘 들어가 있습니다. 한 명을 다른 팟으로 옮깁니다. |
| 전투력이 비어 있음 | 캐릭터 이름이 실제와 다르거나 개명·삭제된 캐릭터일 수 있습니다. 캐릭터 탭에서 이름을 고쳐 주세요. |
| 화면 위에 "동기화 오류"가 뜸 | 저장이 안 된 상태입니다. 새로고침 후 다시 시도해 주세요. |
| 지난주 클리어 표시가 그대로 남아 있음 | 대시보드에서 🏁 주간 클리어 초기화를 눌러 주세요. |
